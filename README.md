# Sheena's App

Upload a photo and add location, timestamp, and satellite-map overlays. The location metadata is built into the app; Gemini and API keys are not required.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Create a production build: `npm run build`
